# Format Age Labels for Chronogram Axis Ticks

Formats numerical node age breaks into clean text strings for timeline
axes.

## Usage

``` r
format_age_labels(x, digits = 1L)
```

## Arguments

- x:

  Numeric vector of geological age values in Ma.

- digits:

  Integer. Decimal precision for rounding. Defaults to \`1L\`.

## Value

Character vector of formatted age labels.
