# Comparative Tree-Space Projection and Topological Validation Pipeline

Quantifies topological congruence between the focal supermatrix
maximum-likelihood tree generated by \`PhyloCactus\` and external
reference phylogenomic hypotheses (e.g., Amaral \*et al.\* 2022,
Thompson \*et al.\* 2024, de Vos \*et al.\* 2025). Employs quantitative
tree distance metrics—including Robinson–Foulds (RF) distances and
Information-Theoretic distances (\`TreeDist\`; Smith, 2020)—and
multidimensional scaling (MDS) tree-space projections to identify
congruent clades and detect topological conflicts across alternative
datasets.

## Usage

``` r
validate_phylogenies(
  trees_mapping_list,
  checklist_csv,
  constraints_map,
  out_dir
)
```

## Arguments

- trees_mapping_list:

  Named list of file paths pointing to Newick/Nexus reference trees and
  focal tree.

- checklist_csv:

  Character. Path to accepted botanical checklist CSV for taxon name
  standardization.

- constraints_map:

  Character. Path to taxonomy mapping CSV file.

- out_dir:

  Character. Destination directory path to save validation output
  tables, tree-space plots, and logs.

## Value

A data frame containing pairwise tree distances, RF metrics, and MDS
coordinates across evaluated trees.
